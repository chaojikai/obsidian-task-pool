# Task Pool

[English](README.md)

把一份普通的 Markdown 待办清单变成可以长期住在里面的需求池：已完成的自动收起，`#标签` 分区变成 Tab，条目像卡片一样拖来拖去，笔记本身钉成一个不会被顶掉的小标签页。文件始终是标准 Markdown，关掉插件内容不受影响。

![带 Tab 栏、已完成折叠行和拖动手柄的需求池笔记](docs/overview.png)

## 功能

### 已完成自动收起

同一列表里连续的已完成项超过阈值（默认 3 条）时，前面的收进一行「已完成 5 项，收起了 2 项」，只留最近几条保住上下文。点击这一行展开，光标进入被收起的范围也会临时展开。编辑视图和阅读视图表现一致。

### 标签分区变成 Tab

一行只写标签，比如 `#Focus #macOS`，下面的内容就是一个分区。笔记里有两个以上分区时正文上方出现 Tab 栏，带未完成数；每个分区自带一层浅底，在「全部」视图里一眼分得开。点某个 Tab 只看这一个产品，`+` 在它末尾新增待办。把 Tab 拖到别的位置，对应的整个分区也会在笔记里跟着挪过去。也可以用路径列表或 `task-tabs` 属性强制开关。

### 像卡片一样拖动

鼠标移到任意列表项、段落、标题或代码块左侧出现 ⋮⋮ 手柄，拖到文中任意位置，或拖到某个 Tab 上转移到该分区。先选中多个块再拖，它们一起走。子项跟着父项，段落自动保留前后空行，Cmd+Z 一次撤销整次移动。

![把一条待办拖向另一个分区，显示落点指示线和拖影](docs/drag.png)

### 空行上也能直接加待办

在待办上回车会自动续一条，但光标不是这么下来的空行就不会。鼠标移到空行，左侧出现一个小 `+`，点一下这一行就变成空待办，缩进跟随上方的列表。分区底部那条空白也一样：在那里点 `+` 就在这个分区末尾加一条。

### 勾选后自动归位

勾选完成时移到已完成段末尾，取消勾选时移回未完成段开头。跳过一条待办去勾后面的，折叠不会被切成两截，光标也留在原处。不喜欢可以在设置里关掉。

### 常驻标签页

把每天常开的笔记列进设置：标签页自动固定、缩成只有图标的小标签、始终排在标签组最前，点别的文件只会开新标签。命令「跳到固定的笔记」或 Obsidian 自带的 ⌘1 随时跳回去。

### 细节

- 还没写内容的待办不计入 Tab 上的未完成数，正在敲的一条不会先被算成未完成。
- 被移动的块落地时短暂高亮，折叠行数量变化时淡入一次，归位到哪里一眼能看到；系统开了「减弱动态效果」时自动关闭。
- 所有操作都有命令：上移 / 下移列表项（含子项）、移动到分区、切换 Tab、上一个 / 下一个 Tab、展开 / 收起已完成、固定 / 取消固定当前笔记。
- 中英文界面跟随 Obsidian 语言。

## 写法示例

```markdown
#数据看板
- [x] 概览增加上月 YoY
- [x] 增加导出
- [ ] 通知入口按下钻分析的 Tab 架构重构

#Larkfocus #MacOS
- [x] 胶囊提醒只出现在主屏幕
- [ ] 主窗口页重新设计
```

## 安装

- **社区插件**：上架后在「设置 → 第三方插件」里搜索 Task Pool。
- **BRAT**：在 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 里添加 `chaojikai/obsidian-task-pool`，上架前也能跟随发布更新。
- **手动**：从 [最新 Release](https://github.com/chaojikai/obsidian-task-pool/releases/latest) 下载 `main.js`、`manifest.json`、`styles.css` 放到 `<vault>/.obsidian/plugins/task-pool/`，再在「第三方插件」中启用 Task Pool。

## 设置

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 保留最近几条 | 3 | 连续已完成项超过该值时收起前面的，0 表示全部收起 |
| 已完成折叠生效范围 | 所有笔记 | 可改为仅显示 Tab 栏的笔记，或关闭 |
| 勾选后自动归位 | 开 | 关掉后勾选只改复选框，不移动位置 |
| Tab 识别方式 | 自动识别 | 两个分区以上显示；「仅指定的笔记」只对路径列表和属性生效 |
| 始终启用的笔记 | 空 | 每行一个库内路径 |
| 笔记属性键 | `task-tabs` | 属性为 true 强制显示，false 强制隐藏 |
| Tab 上显示未完成数 | 开 | |
| 分区加底色 | 开 | 给每个标签分区铺一层浅底和边框 |
| 拖动生效范围 | 所有笔记 | 同上 |
| 空行快捷新增 | 所有笔记 | 在哪些笔记的空行左侧显示 `+`，选项同上 |
| 固定的笔记 | 空 | 每行一个库内路径；命令「固定 / 取消固定当前笔记」也会写到这里，在 Obsidian 里手动取消固定则会从这里移除 |
| 标签页样式 | 仅图标 | 仅图标 / 紧凑 / 默认 |
| 固定在标签栏最前 | 开 | 固定的标签页始终排在同一标签组最前，Obsidian 的「跳转到第 1 个标签页」每次都落到它上面 |
| 手动固定的标签页也用同样式 | 开 | 在 Obsidian 里手动固定的标签页同样缩小并排到最前 |
| 图标 | `list-todo` | 仅图标 / 紧凑样式下显示的 Lucide 图标名，留空用默认文件图标 |

## 路线图

- **0.1** – 首个公开版本：折叠、Tab、块拖动、勾选归位、常驻标签页。
- **0.2** – Tab 可拖动排序、空行快捷新增、分区自带浅底。
- **0.x** – 根据反馈打磨：移动端拖动手感、更多分区操作、纯键盘流程。次版本号加功能，修订号修 bug。
- **1.0** – 进入 Obsidian 社区插件目录。

Task Pool 不在库外存任何数据，也不联网。

## 开发

```bash
npm install --legacy-peer-deps
npm run dev     # 监听模式
npm run build   # 类型检查并构建生产版本
```

两个脚本都把 `main.js`、`manifest.json`、`styles.css` 写到 `dist/`。把 `TASK_POOL_OUT` 指向库里的插件目录就能对着真实笔记库开发：

```bash
TASK_POOL_OUT="<vault>/.obsidian/plugins/task-pool" npm run dev
```

Obsidian 1.13+ 可用 CLI 热重载：`obsidian plugin:reload id=task-pool`
